# 文档结构说明

> 最后更新：2026-02-07

## 1. 活跃文档（当前状态源）

- `docs/下一次对话提示词.md`：当前真实状态 + 下一步任务
- `docs/API文档.md`：最新 API 说明与验收口径
- `docs/开发日志.md`：开发过程记录
- `docs/TODO.md`：当前待办清单
- `docs/status/README.md`：状态与测试报告索引

## 2. 领域文档

- `docs/ops/`：部署与运维文档
- `docs/spec/`：产品与规格文档

## 3. 历史快照文档

以下文档保留历史事实，不做“改写为当前状态”：

- `docs/v3.1.0完成总结.md`
- `docs/status/测试报告-2026-02-03.md`
- `docs/status/测试报告-2026-02-07-核心闭环修复.md`

## 4. 维护规则

1. 每次开发会话结束，至少更新：`开发日志`、`下一次对话提示词`。
2. API 变更时必须同步 `API文档`。
3. 新增测试或验收结论必须写入 `docs/status/` 并在 `docs/status/README.md` 建索引。
