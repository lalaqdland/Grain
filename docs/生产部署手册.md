# Grain 生产部署手册

## 1. 当前线上架构

- 服务器: `capoo-hk` (`47.83.120.83`)
- 应用入口: `https://grain.capootech.com`
- 主域跳转:
  - `https://capootech.com` -> `https://grain.capootech.com`
  - `https://www.capootech.com` -> `https://grain.capootech.com`
- 反向代理: Nginx
- HTTPS: Let's Encrypt (Certbot 自动续期)
- 容器:
  - `grain-frontend` -> `127.0.0.1:3001`
  - `grain-backend` -> `127.0.0.1:8001`

## 2. 路由规则

- 前端: `https://grain.capootech.com/` -> `http://127.0.0.1:3001`
- API:
  - `https://grain.capootech.com/api/v1/*` -> `http://127.0.0.1:8001/api/v1/*`
  - `https://grain.capootech.com/api/health` -> `http://127.0.0.1:8001/health`

## 3. 代码发布（标准流程）

### 3.1 本地准备

```bash
git checkout main
git pull origin main
```

### 3.2 同步代码到服务器

```bash
git archive --format=tar -o .deploy-main.tar main
scp .deploy-main.tar capoo-hk:/opt/gain-project/.deploy-main.tar
ssh capoo-hk "cd /opt/gain-project && tar -xf .deploy-main.tar && rm -f .deploy-main.tar"
```

### 3.3 重建并启动生产容器

```bash
ssh capoo-hk "cd /opt/gain-project && docker compose -f docker-compose.prod.yml up -d --build"
```

### 3.4 发布后验证

```bash
curl -I https://grain.capootech.com
curl https://grain.capootech.com/api/health
curl https://grain.capootech.com/api/v1/info
curl -I https://capootech.com
curl -I https://www.capootech.com
```

## 4. 线上运维常用命令

### 4.1 查看容器状态

```bash
ssh capoo-hk "docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'"
```

### 4.2 查看日志

```bash
ssh capoo-hk "docker logs --tail 200 grain-frontend"
ssh capoo-hk "docker logs --tail 200 grain-backend"
```

### 4.3 重启服务

```bash
ssh capoo-hk "cd /opt/gain-project && docker compose -f docker-compose.prod.yml up -d --force-recreate"
```

### 4.4 Nginx 检查与重载

```bash
ssh capoo-hk "nginx -t"
ssh capoo-hk "systemctl reload nginx"
ssh capoo-hk "systemctl status nginx --no-pager -n 20"
```

## 6. 预览热同步环境（dev 子域）

### 6.1 架构说明

- 预览入口: `https://dev.grain.capootech.com`
- 预览目录: `/opt/gain-preview`
- 预览容器:
  - `grain-preview-frontend` -> `127.0.0.1:3101`
  - `grain-preview-backend` -> `127.0.0.1:8101`
- 同步方式: Mutagen 单向同步（本地 -> 服务器）

### 6.2 启动 Mutagen 同步

```bash
mutagen project start
mutagen sync list
```

### 6.3 预览环境启动

```bash
ssh capoo-hk "mkdir -p /opt/gain-preview"
ssh capoo-hk "cd /opt/gain-preview && docker compose -f docker-compose.preview.yml up -d --build"
```

### 6.4 预览环境验证

```bash
curl -I https://dev.grain.capootech.com
curl https://dev.grain.capootech.com/api/health
curl https://dev.grain.capootech.com/api/v1/info
```

### 6.5 热同步验证（建议）

1. 本地修改 `frontend/src/app/page.tsx` 中一段文案。
2. 观察 1-5 秒后 `https://dev.grain.capootech.com` 页面变化。
3. 验证生产站 `https://grain.capootech.com` 不受影响。

## 7. 回滚方案

### 7.1 回滚到指定提交（推荐）

```bash
# 本地切到要回滚到的提交
git archive --format=tar -o .deploy-rollback.tar <COMMIT_SHA>
scp .deploy-rollback.tar capoo-hk:/opt/gain-project/.deploy-rollback.tar
ssh capoo-hk "cd /opt/gain-project && tar -xf .deploy-rollback.tar && rm -f .deploy-rollback.tar && docker compose -f docker-compose.prod.yml up -d --build"
```

### 7.2 回滚后验收

```bash
curl -I https://grain.capootech.com
curl https://grain.capootech.com/api/health
```

## 8. 关键文件位置

- 服务器项目目录: `/opt/gain-project`
- 生产编排文件: `/opt/gain-project/docker-compose.prod.yml`
- 预览项目目录: `/opt/gain-preview`
- 预览编排文件: `/opt/gain-preview/docker-compose.preview.yml`
- Nginx 配置: `/etc/nginx/conf.d/capootech.com.conf`
- 后端环境变量: `/opt/gain-project/backend/.env`

## 9. 注意事项

- 生产环境不要使用 `next dev`，必须使用 `next build + next start`。
- 后端生产环境不要使用 `uvicorn --reload`。
- 预览环境与生产环境必须使用独立目录和端口，不要共用。
- `backend/.env` 属于敏感配置，不要覆盖或提交到仓库。
- 发布后建议至少观察 10-15 分钟日志，确认无持续重启和 5xx。
